## Լրացուցիչ (ավելի երկար ներկայացման համար)

- `weather Yerevan --demo --forecast`. ամբողջովին առանց ցանցի, հստակ նշված է՝ **DEMO / SAMPLE DATA**։
- `weather Yerevan --output json | python -m json.tool`. մաքուր JSON՝ բացահայտ նշված միավորներով։
- `weather Yerevan --plain --forecast`. միայն ASCII, պարզ տերմինալների և լոգերի համար։
- `weather 0010 --country AM`. ազնիվ «չի գտնվել»՝ քաղաքով որոնելու հուշումով։ Հայաստանի փոստային կոդերը օգտագործվող հանրային ինդեքսներում չկան։
